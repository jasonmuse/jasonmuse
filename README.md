## 🚀 Selected Projects

### 🌪️ [Florida Hurricane Landfall Event Tracker](https://github.com/jasonmuse/riskdesk-florida-landfalls)

A Windows desktop app that reads NOAA's HURDAT2 storm tracks and infers Florida hurricane landfalls from 1900 on using the track geometry alone, without HURDAT2's own landfall marker. Across 2,004 storms it finds 104 landfall events, keeping repeat landfalls by the same storm separate.

Built with **C#, ASP.NET Core, TypeScript, Electron, NetTopologySuite, and xUnit**. Ships as a [portable Windows app](https://github.com/jasonmuse/riskdesk-florida-landfalls/releases/latest).
